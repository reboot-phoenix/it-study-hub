## ` 01 ` &nbsp; What Is This?

Most learning platforms give you content and leave you to figure out the rest.

**IT Study Hub doesn't.**

It's a complete end-to-end learning environment — placement quiz, structured course tracks, a live in-browser IDE, an AI mentor that gives hints without giving away answers, a student leaderboard, a file-sharing hub, and a tech blog. Every feature was built from scratch by four IT students at Techno India University, in pure HTML, CSS, and JavaScript.

No React. No Vue. No Bootstrap. No build pipeline.  
Just 24 pages of pure HTML, CSS, and JS — and a dark cyberpunk UI that looks nothing like a university project.

**[→ See it live](https://www.itstudyhub.dpdns.org)**

<br>

## ` 02 ` &nbsp; The Practice Panel

> *Code in the browser. Get unstuck fast. No installs. No excuses.*

The centrepiece of IT Study Hub is a fully in-browser coding environment — powered by the same editor engine that runs VS Code.

| Component | What it does |
|---|---|
| **Monaco Editor** | VS Code's editor, in the browser — syntax highlighting, IntelliSense, the works |
| **Judge0 CE** | Real code execution across 6 languages, with stdin support |
| **78 Problems** | Curated across Beginner / Intermediate / Advanced tiers |
| **AI Mentor** | Contextual hints on demand — guides your thinking, never just hands you the answer |

Execution time is displayed inline. Errors are highlighted. You can test with custom input.  
It's as close to a real dev environment as a browser can get.

## ` 04 ` &nbsp; Placement Quiz

**Don't start at the wrong level.**

Before you commit to a track, the placement quiz finds where you actually belong — not where you think you are.

- 150 questions total — 25 MCQs per subject across 6 subjects
- Spread across 3 difficulty tiers (Beginner / Intermediate / Advanced)
- Instant result with score breakdown by tier so you understand the gaps
- Zero dependencies — fully vanilla JavaScript

## ` 05 ` &nbsp; Authentication & Access Control

Passwords are a UX problem. IT Study Hub skips them entirely.

**Passwordless login** via Firebase — magic link / email OTP. No password to forget, no password to reuse on five other sites. Session persistence keeps you logged in across tabs and reloads via `onAuthStateChanged`.

Access tiers are enforced at the **Firestore rules level** — not just the UI.

```
free  →  public content only
pro   →  all lessons, all PDFs, priority support
elite →  everything + certificates + lifetime access
admin →  full platform control
```
