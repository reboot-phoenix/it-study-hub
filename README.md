## What is IT Study Hub?

IT Study Hub is a full-featured educational platform for IT students at Techno India University. It brings together 6 programming language tracks, a live in-browser IDE with AI-powered mentoring, a smart placement quiz system, passwordless authentication, student file sharing, premium gated content, and a tech blog — all built from scratch in pure HTML, CSS, and JavaScript.

No frameworks. No templates. No build tools.

**[Visit the live site →](https://www.itstudyhub.dpdns.org)**

---

## Features

### Live Practice Panel

A fully in-browser coding environment — no installs, no signups needed.

- **Monaco Editor** — the same engine powering VS Code, running entirely in the browser
- **Real code execution** via Judge0 CE across all 6 supported languages
- **70+ curated problems** organized into Beginner / Intermediate / Advanced tiers
- **AI Mentor** powered by the Anthropic Claude API — contextual hints, not spoilers
- Stdin support, execution time display, and inline error highlighting

### Placement Quiz System

Find the right starting point before committing to a course.

- 25 MCQs per subject across 3 difficulty tiers
- Instant result: Beginner / Intermediate / Advanced
- Score breakdown by difficulty level
- Built entirely in vanilla JavaScript — zero dependencies

### Six Course Tracks

Every track runs **Beginner → Intermediate → Advanced** so no student starts lost or gets held back.

|:---:|---|---|

### Authentication & Access Control

![Firebase](https://img.shields.io/badge/Firebase-FFCA28?style=flat-square&logo=firebase&logoColor=black) Firebase Authentication with **passwordless login** (magic link / email OTP), session persistence via `onAuthStateChanged`, and role-based access control — `free / pro / elite / admin` — enforced at the Firestore rules level.

### Premium Plans

![Razorpay](https://img.shields.io/badge/Razorpay-02042B?style=flat-square&logo=razorpay&logoColor=3395FF) Razorpay-integrated payments across three tiers:

| Plan | Price | What you get |
|------|-------|---------|
| **Starter** | ₹199 | Intermediate lessons + select PDFs |
| **Pro** | ₹499 | All lessons, all PDFs, priority support |
| **Elite** | ₹999 | Everything + certificates + lifetime access |

### Global Leaderboard

XP-based student rankings pulled live from Firestore.

### File Share Hub

A collaborative space for students to upload and download class notes, past papers, and PDF handouts.

### Tech Blog

Editorial content covering AI, Cybersecurity, Web Development, and IT career topics.
