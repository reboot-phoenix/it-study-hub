## ` 01 ` &nbsp; What Is This?

Most learning platforms give you content and leave you to figure out the rest.

**IT Study Hub doesn't.**

It's a complete end-to-end learning environment — placement quiz, structured course tracks, a live in-browser IDE, hints that guide you without giving away answers, a student leaderboard, a file-sharing hub, and a tech blog. Every feature was built from scratch by four IT students at Techno India University, in pure HTML, CSS, and JavaScript.

No React. No Vue. No Bootstrap. No build pipeline.  
Just 25 pages of pure HTML, CSS, and JS, one small Cloudflare Worker for the parts that must be trusted (payments, XP, premium content, code running, sign-in codes), and a dark cyberpunk UI that looks nothing like a university project.

**[→ See it live](https://www.itstudyhub.dpdns.org)**

## ` 02 ` &nbsp; The Practice Panel

> *Code in the browser. Get unstuck fast. No installs. No excuses.*

The centrepiece of IT Study Hub is a fully in-browser coding environment — powered by the same editor engine that runs VS Code.

| Component | What it does |
|---|---|
| **Monaco Editor** | VS Code's editor, in the browser — syntax highlighting, IntelliSense, the works |
| **Judge0 CE** | Real code execution across 6 languages, with stdin support. Runs through our own server, so you sign in to run code |
| **77 Problems** | Curated across Beginner / Intermediate / Advanced tiers |
| **Hints** | Hints on demand for each problem. They guide your thinking, never just hand you the answer |

Execution time is displayed inline. Errors are highlighted. You can test with custom input.  
It's as close to a real dev environment as a browser can get.

## ` 05 ` &nbsp; Authentication & Access Control

Passwords are a UX problem. IT Study Hub skips them entirely.

**Three ways in:** Google, GitHub, or a **6-digit code sent to your email**: type your address, type the code, you are in. Codes work for 10 minutes, allow five tries and can be used once. The code check runs on our server behind a Cloudflare Turnstile challenge, and the same email always lands in the same account, whichever way you sign in.

Access is enforced on the **server and in Firestore rules**, not just in the page:

```
free   →  public lessons, quizzes and the practice panel
paid   →  premium lessons and PDFs (Starter 6 months · Pro 12 months · Elite lifetime)
admin  →  the admin dashboard, set with the `role` field by hand, never from the browser
```

Premium lessons and PDFs are not in the page source at all: the Worker hands them out only after checking your plan.

## ` 08 ` &nbsp; Tech Stack

> No frameworks. No shortcuts.

| Layer | Technology |
|---|---|
| Structure | HTML5 |
| Styling | CSS3 — Grid · Flexbox · Animations · 5 modular stylesheets |
| Logic | Vanilla JavaScript ES6+ — no frameworks |
| Server | One Cloudflare Worker (`worker.js`): payments, XP, premium content, code runner, email sign-in codes, leaderboard |
| IDE Engine | Monaco Editor (via CDN) |
| Code Execution | Judge0 CE, called by the Worker |
| Auth | Firebase Authentication — Google, GitHub and email codes (custom tokens) |
| Database | Cloud Firestore, protected by `firestore.rules` |
| File Storage | Firebase Storage (profile pictures), protected by `storage.rules` |
| Premium content | Cloudflare KV |
| Payments | Razorpay, verified on the server |
| Email | Google Apps Script relay (`mail-relay.gs`) sending from the project Gmail |
| Bot protection | Cloudflare Turnstile, verified on the server |
| Hosting | Cloudflare Workers static assets + custom domain (source on GitHub) |
| Typography | Bebas Neue · DM Sans · JetBrains Mono |

<br>

## ` 10 ` &nbsp; Run It & Configure It

The pages are plain files: open `index.html` to look around. Sign-in, payments, XP, premium content and the code runner need the Worker.

```bash
git clone https://github.com/esd-project-tiu/it-study-hub.git
cd it-study-hub
npm test               # Worker, shared-module and site checks. No install, no network
npx wrangler dev       # run the Worker and the site locally
```

**Secrets** (set in the Cloudflare dashboard → your Worker → Settings → Variables and Secrets; never commit them):

| Name | What it is for |
|---|---|
| `FIREBASE_SERVICE_ACCOUNT` | Google service account JSON with the *Cloud Datastore User* and *Firebase Authentication Admin* roles |
| `OTP_SECRET` | Keys the hashing of email codes; also the key for the setup check |
| `TURNSTILE_SECRET` | Verifies the Turnstile challenge on the server |
| `MAIL_RELAY_URL` / `MAIL_RELAY_SECRET` | The Apps Script that sends code emails |
| `RAZORPAY_KEY_SECRET` / `RAZORPAY_WEBHOOK_SECRET` | Payment verification |
| `JUDGE0_KEY` *(optional)* | RapidAPI key if you use a hosted Judge0 |

Plain variables (`RAZORPAY_KEY_ID`, `JUDGE0_URL`, `EMAIL_FROM`) live in `wrangler.toml`. To see which pieces are working, call `/api/setup-check` with the header `X-Setup-Key: <OTP_SECRET>`.
